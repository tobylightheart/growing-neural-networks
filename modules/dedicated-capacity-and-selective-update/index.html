Dedicated capacity · selective update · sparse read-out

Capacity you can write, directions you can read

Two sparse mechanisms can look alike while doing opposite jobs. Memory layers add a large bank of trainable values to the model. A sparse autoencoder reads an existing activation through a learned dictionary. One enlarges what can be stored; the other gives coordinates for inspecting and steering what is already there.

Lample et al. 2019

adds capacity

A huge table, a tiny active set

Two sub-key sets implicitly define their product. A query finds exact top-k product keys; their scores weight a small set of learned value vectors. The values carry the bulk of up to a billion reported parameters, while only selected slots update for an input.

Berges et al. 2024

scales capacity

128B memory parameters

The later system replaces selected FFNs with memory, shares the pool across layers, shards value dimensions across GPUs, and optimizes the bandwidth-bound lookup. Its abstract reports 128B memory parameters trained over one trillion tokens with base models up to 8B.

Lin et al. 2025

selects writes

Update the least-general slots

Batch-specific memory accesses are ranked against background usage by TF–IDF. Only top-t values receive gradients; all accessed values still contribute to the forward pass. The rest of the memory and model stay frozen.

Templeton et al. 2024

adds a read-out

Features are coordinates, not new storage

An SAE encoder maps an existing activation into sparse feature coefficients; its decoder reconstructs the activation from learned directions. Clamping a feature can steer behavior, but the auxiliary SAE neither inserts that feature into Claude nor adds writable base-model memory.

Do not confuse the two sparse spaces

Memory slotA parameter row inside the language model. Retrieval uses its learned key; updating its value changes model storage.
SAE featureA coordinate in an auxiliary reconstruction of model activity. Its decoder direction is a read-out learned from activations.
SteeringClamping the read-out coordinate intervenes in a forward pass. It demonstrates causal influence; it does not establish that the SAE added capacity.
