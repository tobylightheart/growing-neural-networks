Frozen-base parameter addition · interactive comparison

Where do the new parameters live?

Adapters, LoRA and MoLE all add a small number of trainable parameters to a large model that stays frozen. They do not put them in the same place — and that choice, not the parameter count, decides what removal costs and what inference costs.

Not human-reviewed Automated readings of the public arXiv and ar5iv sources; check the linked review drafts before reusing details.

Adapters · Houlsby et al. 2019

New layers inside the block

Two adapters per Transformer layer: one after the attention output projection, one after the feed-forward sub-layer, each placed before the block's skip connection is added back. Each is a down-projection to m, a nonlinearity, an up-projection to d, with its own internal skip connection.

Added per layer: (2md + d + m) × 2

What stays frozen, and what does not?

The pre-trained Transformer weights are fixed. The paper also trains new layer-normalization parameters per task and the final classification layer, so the trainable set is slightly larger than the adapters alone. Near-zero initialization makes each adapter an approximate identity at step one.

LoRA · Hu et al. 2021

A low-rank delta on a matrix that already exists

No new layer. For a frozen matrix W₀, the forward pass becomes h = W₀x + BAx with B of shape d×r and A of shape r×k. B starts at exactly zero, so training begins from the base function rather than near it. The paper adapts Wq and Wv and freezes the MLP modules.

Added per adapted matrix: r(d + k)

This configuration: — parameters

What stays frozen, and what does not?

The pre-trained weights are frozen; only A and B move, scaled by α/r. Because the delta has the shape of the weight it modifies, it can be folded in as W = W₀ + BA before serving — which is why the paper claims no additional inference latency, in contrast to adapters' extra sequential layers.

MoLE · Wu et al. 2024

A gate over modules that already exist

Nothing new is added to the network's capacity. Each layer of each already-trained LoRA is treated as a distinct expert, and a learnable gating function inside each layer produces softmax weights over their outputs. Hierarchical control comes from a balancing loss plus a domain-specific loss.

Added: the gating function only

This configuration: —

What stays frozen, and what does not?

Both the pre-trained model and every trained LoRA are frozen; only the gate's parameters are optimized. The gate's own parameter count depends on the number of experts and the layer width, and the reviewed text does not state a formula — so this module reports it as not stated rather than guessing.

Cost of the addition

Both counts assume the papers' own configurations: two adapters per layer, and LoRA on two attention matrices per layer with k = d. They are the papers' formulas applied to your sliders, not a measurement of any model.

Composition without addition

MoLE's gate weights the trained LoRAs it is given. At inference, an unwanted branch can be masked out and the remaining weights redistributed proportionally — no retraining, and nothing unfrozen.

Three questions the parameter count does not answer

Where do they live?Adapters: new layers inside the block. LoRA: a delta on an existing matrix. MoLE: nowhere new — a gate over modules already trained.
What does removal cost?Adapters: delete the module and the original block is back exactly. LoRA: drop the delta if unmerged, or subtract BA if merged. MoLE: mask the branch and renormalize.
What stays frozen?Adapters and LoRA: the pre-trained weights. MoLE: the pre-trained weights and every LoRA — only the gate is trained.

The lineage question this raises for the rest of the book: classic constructive learning grew the architecture and had to protect what it had already learned. Two of these three methods protect everything and add beside it, and the third adds nothing at all.
