DNC · global history

Error progress has flattened

Ash compares the recent drop in average squared error with error at the start of the current topology. A sufficiently small normalized drop, after a complete back-history window, triggers one hidden node.

Grow when drop < 0.050 and the window does not cross an insertion.

What happens after insertion?

The new hidden node connects to inputs and outputs; ordinary backpropagation continues over old and new weights. DNC explicitly does not freeze the old network.

Cascade-Correlation · stalled fit + feature search

The current outputs have stopped improving

Output-weight training first reaches its stopping criterion while error remains. That opens a candidate phase; residual correlation then answers which feature to install, not by itself whether the current network needs capacity.

What happens after installation?

The winning candidate's incoming weights freeze permanently. Output-side weights remain trainable, and later candidates may use earlier hidden units as inputs.

RAN · local novelty

This input is both far away and badly predicted

Platt's two-part novelty test asks whether the input lies beyond the current distance scale and whether output error exceeds desired accuracy. Both conditions are required.

Grow when distance > ε(t) = 0.50 and error > δ = 0.20.

What happens after allocation?

A local unit is centered on the input, its output weight is initialized to the residual, and its width depends on nearest-center distance. When no unit is allocated, LMS updates output weights and offset while gradient descent moves centers.
