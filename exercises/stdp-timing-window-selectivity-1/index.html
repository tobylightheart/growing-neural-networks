Scope guard

This is not a claim that STDP alone grows neurons or creates new synapses. It follows the active stdp-hidden-pattern-construction bundle by showing how timing-dependent synaptic updates can grow selectivity for predictive inputs. Structural growth still needs a separate trigger, recruitment rule, or constructive algorithm.

The plotted curve is intentionally simple. The Morrison2008 review is included as a simulation-model guardrail: phenomenological STDP rules differ in state variables, traces, bounds, and implementation choices, so the exercise teaches a comparison axis rather than a definitive biological rule.
