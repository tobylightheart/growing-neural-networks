# What Counts as Evidence for More Capacity?

A compact, source-linked comparison of Dynamic Node Creation, Cascade-Correlation, and Platt's Resource-Allocating Network.

The interaction separates three questions that are often blurred together:

- DNC: has global error progress flattened over the current topology's history?
- Cascade-Correlation: has output fitting stalled, and which candidate feature best follows the residual?
- RAN: is this input both far from existing local centers and inaccurately predicted?

It also keeps each post-growth policy visible: continued backpropagation, frozen installed feature inputs, or local allocation plus LMS/center adaptation. DNC and Cascade-Correlation link directly to the repository's runnable artifacts. RAN is decision-logic only because no reproduction is claimed.

All mechanism copy is explicitly not human-reviewed. The linked reviews document primary-source access, extraction limits, and implementation deviations.
