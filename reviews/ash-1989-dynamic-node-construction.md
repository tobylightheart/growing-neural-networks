# Dynamic Node Construction for the Backpropagation Algorithm

## Review status

Queued for detailed review.

## Working summary

Dynamic Node Construction is an early constructive neural network method associated with adding hidden units during backpropagation training. It is one of the seed papers for comparing different ways neural networks can grow rather than relying on a fixed architecture chosen before training.
