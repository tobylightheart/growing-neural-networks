Synthesis lens: growth rule versus topology commitment

Across the current draft reviews, one cautious pattern is now worth tracking explicitly: adding units is not the same as escaping architectural assumptions. Cascade-Correlation uses residual-error correlation to install and freeze useful hidden features, while the recurrent Cascade-Correlation limitations paper warns that a growth rule can still commit the learner to a topology that is too restrictive for some sequence tasks. The thesis-derived taxonomy broadens this into three questions for every constructive method: when does structure change, what changes, and how are new parameters chosen?
