Five-draft synthesis · not human-reviewed

One base eSNN sequence, then two different adaptation branches

The mechanism-level sequence below comes from the public thesis taxonomy, which cites the base eSNN literature. The five automated paper drafts establish lineage roles and learning settings; they do not independently verify every later variant's equations or thresholds.

  1. 1 · Current input → candidate parameters

    For each labelled sample, simulate the input, rank interface-neuron spikes by time, then calculate a proposed output neuron's weight vector and activation threshold. Earlier spikes receive larger rank-order factors, so spike timing shapes the candidate before any add/merge decision.

  2. 2 · Candidate → novelty test

    Compare that candidate with existing neurons for the same class. The thesis pseudocode uses the minimum Euclidean distance between weight vectors as the similarity quantity.

  3. 3 · Similar → merge; novel → add

    If the nearest same-class neuron is inside the similarity threshold, merge the candidate's weights and threshold into it; otherwise add a new output neuron for the sample's class. Parameter calculation therefore precedes the structural decision.

Mechanism source: thesis-taxonomy review · Chapter 2 source and pseudocode

Supervised branch

Class-labelled construction

The base eSNN sequence is presented for supervised pattern recognition: novelty is checked against neurons belonging to the desired class. Wysoski2010 is the application anchor; Kasabov2013 is the dynamic eSNN/deSNN anchor; and Wang2014 names a supervised adaptive-structure branch. The current drafts do not establish that all three use an identical candidate formula, distance threshold, or merge update.

Unsupervised branch

Structural plasticity, not unlabelled eSNN

Roy2017 explicitly anchors online unsupervised structural plasticity. It belongs in the broader constructive-spiking lineage, but the draft does not justify describing it as the base eSNN novelty/merge loop. Its exact creation, deletion, rewiring, candidate-performance, and threshold rules remain open here.

What the five drafts contribute

  • Schliebs2013: survey vocabulary and the ECoS/eSNN lineage.
  • Wysoski2010: the base eSNN application anchor used by the thesis mechanism account.
  • Kasabov2013: the dynamic eSNN/deSNN continuation, with exact dynamic-synapse and adaptation mechanics still open.
  • Wang2014: the supervised adaptive-structure continuation, with the roles of pruning, radial-basis structure, and supervision still open.
  • Roy2017: the unsupervised structural-plasticity bridge, not evidence that every branch shares the eSNN add/merge rule.

Bundle guardrail

The active bundle has enough public draft reviews for a paper-card bridge: Lightheart2018 supplies the thesis taxonomy vocabulary, Schliebs2013 supplies eSNN lineage vocabulary, Wysoski2010 provides an application anchor, Kasabov2013 names the dynamic eSNN/deSNN detail slot, Wang2014 names the supervised adaptive-structure slot, and Roy2017 names the shared online structural-plasticity bridge.
